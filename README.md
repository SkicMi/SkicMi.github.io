# Danijel — Portfolio

Personal portfolio site built with Astro and deployed to GitHub Pages. The first version focuses on WeaverDeck only.

## Local development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

## Publish

Push to `main`. The GitHub Actions workflow builds and deploys the static site to `https://skicmi.github.io`.

The WeaverDeck demo is from an isolated local profile and includes a note that its Remote View window is simulated.
